# متجر بطاطا 🥔 | Batata Store

مشروع Next.js جاهز للنشر الفعلي على الإنترنت (بحيث يظهر بنتائج قوقل بعد الفهرسة).

## شغّله على جهازك (اختياري)

```bash
npm install
npm run dev
```

بعدها افتح http://localhost:3000

## النشر الحقيقي على الإنترنت (الطريقة الموصى بها: Vercel)

1. ارفع هذا المجلد على GitHub (أنشئ repo جديد وارفع الملفات).
2. روح على https://vercel.com وسجّل دخول بحساب GitHub.
3. اضغط "Add New Project" واختر الـ repo — Vercel يكتشف Next.js تلقائيًا ويبنيه وينشره بضغطة واحدة.
4. بعد النشر بتاخذ رابط مباشر (مثل `batata-store.vercel.app`)، وتقدر تربط دومين خاص بك من إعدادات المشروع.

بديل: نفس الخطوات تشتغل على **Netlify** (netlify.com) بنفس الطريقة تقريبًا.

## مهم جدًا — الفرق عن نسخة المعاينة

- **رفع الصور من الجهاز حيقيًا شغّال** هنا (كان مقيّد بس داخل معاينة Claude، مو مشكلة بالكود).
- التخزين الحين يعتمد على **localStorage** في متصفح الزائر نفسه. يعني:
  - كل زائر يشوف نفس المنتجات الافتراضية.
  - لو الأدمن ضاف منتج من جهازه، هذا التعديل يظهر له بس (بمتصفحه)، ومو للزوار الثانين، لأنه ما فيه قاعدة بيانات حقيقية بعد.
- عشان الأدمن يضيف منتجات/أقسام وتظهر **لكل الزوار فعليًا**، لازم قاعدة بيانات حقيقية (مثل Supabase أو Firebase) بدل localStorage — أقدر أساعدك تربطها إذا تبي، بس تحتاج حساب مجاني بأحد هالخدمتين.
- الدفع الحقيقي (بوابة دفع) وتسجيل الدخول الآمن (Authentication حقيقي) برضه يحتاجون نفس الشي — قاعدة بيانات + مزوّد دفع فعلي (مثل Moyasar أو Stripe).

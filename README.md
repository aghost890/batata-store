# متجر بطاطا 🥔

متجر حسابات جاهزة. Next.js 14 + Supabase، والنشر على Netlify من GitHub.

- الواجهة الرئيسية: `components/BatataStore.jsx`
- صفحات قانونية مستقلة (للفهرسة): `app/terms`, `app/privacy`, `app/refund`
- متغيرات البيئة: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- تشغيل محلي: `npm install && npm run dev`
